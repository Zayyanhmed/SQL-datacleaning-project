# SQL Data Cleaning & Exploratory Data Analysis

## Project Overview

This project demonstrates the use of SQL for data cleaning and exploratory data analysis. The project focuses on transforming raw data into a structured and analysis-ready dataset, followed by exploratory analysis to identify patterns, trends and key insights.

## Objectives

- Clean and prepare raw data for analysis
- Identify and handle missing or inconsistent values
- Validate data quality and structure
- Explore patterns and trends within the dataset
- Analyse key variables using SQL
- Generate meaningful insights from the data

## Project Structure

| File | Description |
|---|---|
| `01_data_cleaning.sql` | SQL queries used to clean, validate and prepare the dataset |
| `02_exploratory_data_analysis.sql` | SQL queries used to explore the cleaned dataset and identify patterns and trends |

## SQL Techniques Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- Aggregate functions
- CASE statements
- Data cleaning and transformation
- Missing-value handling
- Date analysis

## Data Cleaning

The data-cleaning stage focused on preparing the raw dataset for reliable analysis. This included checking data quality, identifying inconsistencies and transforming the data into an analysis-ready format.

## Exploratory Data Analysis

The cleaned dataset was analysed using SQL to identify patterns, trends, distributions and relationships between variables.

The analysis included:

- Summary statistics
- Category-level analysis
- Trend analysis
- Distribution analysis
- Identification of key patterns
